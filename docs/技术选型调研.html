0. 先搞懂:项目的三块 + 两层 AI

StudyLamp 不是"一个程序",而是三个部件,分别住在三个地方:

① 采集端(树莓派,孩子书桌) ──上传事件──▶ ② 后端(云) ◀──拉数据── ③ 小程序(家长手机)

而其中"AI"其实是完全不同的两层,这是你最需要先理解的决策点 —— 尤其你问的"本地要不要 AI 识别视频流,还是纯 OCR 就行":

第一层:坐姿监控第二层:作业批改
干什么判断低头/驼背/玩手机认题目、判对错、给建议
输入摄像头连续视频流偶尔拍的几张照片
技术人体姿态识别(MediaPipe)视觉大模型 VLM
跑在哪本地树莓派 · 免费云端 API · 按量付费
关键澄清:纯 OCR 做不了坐姿监控。 OCR 只能把图片里的文字变成文本,它根本不知道人有没有低头驼背。判断坐姿是"认人体骨骼关键点(肩、颈、眼、手腕)",和 OCR 是两套毫不相关的技术。所以坐姿这层必须用姿态识别模型,不是 OCR、也不用云端大模型。

1. AI 选型(最关键)

第一层 · 坐姿监控 → 本地 MediaPipe,免费

  • 用什么:Google MediaPipe(Pose 33 个人体关键点 + Hands 21 个手部关键点),Apache-2.0 开源免费,树莓派可直接 pip install mediapipe 用 CPU 跑。
  • 够不够:够。坐姿是"慢变量",每 1-2 秒抽 1 帧检测就足够,持续几秒判定为低头/离席/玩手机才告警。这个采样率纯 CPU 完全够用。
  • 要不要买 AI 加速器(Hailo AI HAT+,约 500-800 元):MVP 不用买。它只在"高帧率 + 多任务(再叠人脸/物体识别)"时才有意义,对单纯坐姿监控是过度配置。
  • 隐私铁律:原始视频绝不上传,只上传"告警事件 + 缩略图"。既省带宽,更是儿童数据合规的底线。

第二层 · 作业批改 → 国产视觉大模型(不用 Gemini)

你说"服务端不一定要 Gemini" —— 完全正确。调研结论也是不推荐 Gemini:

  • 不推荐 Gemini 国内大陆无法直接访问(需海外服务器/代理);更重要的是把儿童影像发给境外 AI 有数据出境合规风险。

主推国产多模态大模型(价格已尽量核实,标*的建议下单前上官网确认当日价):

百度 ERNIE-4.5-Turbo-VL0.0030.009实名送 20 元券正式首选

不需要单独 OCR。 现代视觉大模型自带认字能力,直接把作业照片喂给它,一次调用就能"识别题目 + 判对错 + 给建议"。单独做 OCR 反而多一次调用、丢失版面信息、还多花钱。
成本小到可忽略: 一个孩子每天拍 5 次作业 ≈ 每月 150 次,月成本 —— GLM-4V-Flash 0 元;ERNIE/Qwen/豆包 约 1-3 元。姿态那层永久免费。

代码现在写的是 Gemini,选定国产模型后可平滑替换(接口可插拔),改动很小。

2. 服务端部署与价格

重磅结论:微信云托管(CloudRun)可能免掉"备案"这道最耗时的坎。 小程序通过微信内部通道直连后端,走微信分配的默认域名,不需要你自己备案;还原生支持 Docker + FastAPI + WebSocket(你项目正好都用),调用自动带 openid 省一套登录鉴权,没流量时缩容到 0。只有你想绑"自己的公网域名"时才需备案。

  • 域名:.com 约 85 元/年,.cn 约 38 元/年。
  • ICP 备案:本身免费,但必须绑一台国内服务器,审核要 2-4 周(全项目最耗时环节)。海外服务器无法备案、也躲不过。
  • HTTPS 证书:免费 DV 证书 / Let's Encrypt 完全够用,不用买。
  • 海外 VPS 不推荐:灰色地带、访问慢、WebSocket 实时性差,还有合规风险。用云托管同样免备案且更快。

3. 数据库选型

现在用 SQLite 就是最优解,别动。 你的数据量(单个/少数孩子、每天几百到几千条)对 SQLite 是"玩具级"负载,余量巨大。云托管数据库对这场景是杀鸡用牛刀(常驻起来月费奔着几百元去)。
阶段用什么成本
MVP / 自家用(现在)SQLite + 开 WAL + 单 worker0 元
小范围分享仍可 SQLite,出现 database is locked 再迁0 元
多用户 / SaaS 化同一台服务器自建 PostgreSQL(免费,几小时迁移)0 元(只用服务器)
商业化 / 要 SLA云托管 RDS / TDSQL-C数百元/年起
  • 现在要做的唯一优化:开 WAL 模式(PRAGMA journal_mode=WAL)+ 保持单 worker,规避唯一的真实瓶颈"并发写锁"。这个我可以顺手帮你改。
  • 备份:每天 sqlite3 .backup 拷一份传对象存储(阿里云 OSS 0.12 元/GB/月),一年几块钱,且多半落在免费额度内 = 0 元。
  • 迁移信号:反复 database is locked / 要多 worker 写库 / 多机共享数据 / 从"1 个家庭"变"几十上百家庭并发"。

4. 微信小程序部署与价格

项结论
注册费个人主体注册 0 元。那 300 元是企业微信认证费,你用不到。
给家人用走体验版,完全免审核。个人号最多加 15 个体验成员(家人足够),扫二维码即用。
公开发布要提交审核(1-7 个工作日,可能反复);要连自己后端域名就要备案。
域名备案只要连自己的后端域名就绕不掉(除非用方案 A 微信云托管);免费但等 2-4 周。
合规提醒涉及未成年人数据。建议定位为"家长(监护人)使用的工具类"应用,弱化"面向儿童教育",能降低类目门槛和法律风险(《未成年人网络保护条例》要求监护人同意)。
省事路径:体验版 + 微信云托管(免备案)→ 近乎 0 成本、当天让家人用上。有公开需求时再走备案 + 审核转正式版。

5. 给你的决策建议(分阶段)

阶段一:让它先跑起来 / 自家用(推荐现在做)

  • 坐姿:MediaPipe 本地跑(免费,不买加速器)
  • 作业批改:智谱 GLM-4V-Flash(免费),直接喂照片,不做 OCR
  • 数据库:SQLite(开 WAL),继续用
  • 后端:微信云托管(免备案)或先用你自己电脑本地联调
  • 小程序:体验版,加家人为体验成员,免审核
  • → 总花费:接近 0 元,几天内能用

阶段二:公开发布(确认阶段一跑通后再做)

  • 作业批改换付费国产模型(ERNIE-4.5-Turbo-VL / GLM-4.5V),月成本个位数
  • 若不用云托管:买国内轻量服务器 + 域名 + ICP 备案(2-4 周)
  • 小程序配域名白名单 → 上传 → 提交审核 → 发布
  • 补齐安全鉴权(见代码仓库 docs/CODE-REVIEW-TODO.md 第二批)
